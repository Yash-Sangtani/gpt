# gpt
Replicating the transformer architecture, following Andrej Karpathy's
["Let's build GPT from scratch"](https://www.youtube.com/watch?v=kCc8FmEb1nY) video.

Character-level language model trained on the tiny Shakespeare dataset.

## Files
- `data/input.txt` — tiny Shakespeare dataset (downloaded from Karpathy's char-rnn repo)
- `requirements.txt` — dependencies (just `torch`)

Model code lives here as it's written.

## Setup
```bash
pip install -r requirements.txt
```
